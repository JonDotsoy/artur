# Artur Brand Guidelines

## Overview

Artur is a lightweight, infrastructure-agnostic web framework for Node.js and Bun that focuses on providing **clear routes** for web applications. The brand identity reflects this core principle through its visual elements and messaging.

## Brand Mission

Artur represents **clarity in routing** - a compass that guides developers through the complexity of modern web development with simple, declarative routing solutions that work across any JavaScript runtime.

## Visual Identity

### Logo Composition

The Artur logo consists of two main elements:

1. **Symbol**: A compass icon (🧭) representing navigation and clear direction
2. **Logotype**: The wordmark "Artur" set in Inter typeface

### Symbol: The Compass

The compass serves as the primary brand symbol and embodies our core value proposition:

- **Navigation**: Guides developers through routing decisions
- **Clear Direction**: Represents the framework's declarative approach
- **Universal Tool**: Like a compass works anywhere, Artur works across runtimes
- **Precision**: Exact routing with URLPattern-based matching
- **Reliability**: Dependable navigation for any web application

#### Symbol Usage

- File location: `docs/brand/assets/symbol.svg`
- The compass symbol can be used independently for favicons, app icons, and compact branding
- Maintains its meaning and recognition even at small sizes
- Works effectively in monochrome and color applications

### Logo Configuration

The complete logo combines the compass symbol with the "Artur" wordmark:

- **Layout**: Horizontal arrangement with symbol on the left, text on the right
- **Proportions**: Rectangular format optimized for headers and documentation
- **File location**: `docs/brand/assets/logo.svg`

## Typography

### Primary Typeface: Inter

The Artur brand uses **Inter** as its primary typeface for all brand applications:

#### Why Inter?

- **Legibility**: Excellent readability at all sizes, crucial for developer tools
- **Modern**: Contemporary design that reflects cutting-edge technology
- **Versatile**: Works well in both interface and documentation contexts
- **Open Source**: Aligns with the framework's open-source philosophy
- **Technical**: Designed for digital interfaces, perfect for developer-focused brand

#### Usage Guidelines

- Use Inter for the main "Artur" wordmark
- Apply Inter in documentation, website headers, and brand materials
- Maintain consistent weight and spacing across applications

## Brand Values Expressed Through Design

### Clarity

- **Clean lines** in the compass symbol
- **Clear typography** with Inter's high legibility
- **Simple composition** without unnecessary decorative elements

### Reliability

- **Geometric precision** of the compass
- **Consistent proportions** across all brand elements
- **Timeless design** that won't feel outdated

### Flexibility

- **Modular design** allows symbol and wordmark to work independently
- **Scalable graphics** work from favicon to billboard sizes
- **Adaptable** to various backgrounds and contexts

## Brand Messaging

### Tagline Concepts

- "Clear Routes, Everywhere"
- "Navigate with Confidence"
- "Your Routing Compass"
- "Direction for Modern Web Development"

### Key Messages

- **Infrastructure Agnostic**: Works with any JavaScript runtime
- **Declarative Routing**: Clear, URLPattern-based route definitions
- **Developer First**: Built for developer experience and productivity
- **Standards Based**: Uses Web APIs for future-proof development

## Usage Guidelines

### Logo Applications

#### Preferred Usage

- Use the complete logo (symbol + wordmark) for primary brand applications
- Maintain adequate clear space around the logo
- Ensure sufficient contrast against backgrounds

#### Symbol-Only Usage

- Appropriate for favicons, app icons, and space-constrained applications
- Social media profile images
- Loading indicators and UI elements

### Color Guidelines

While specific brand colors aren't defined in this document, the compass and typography should:

- Work effectively in monochrome applications
- Maintain readability in both light and dark themes
- Adapt to the visual style of documentation and interface contexts

### Prohibited Uses

- Do not stretch or distort the logo proportions
- Do not separate the compass from the wordmark in primary applications
- Do not use alternative typefaces for the "Artur" wordmark
- Do not add effects, shadows, or decorative elements

## Technical Specifications

### File Formats

- **Primary Format**: SVG (vector graphics for scalability)
- **Logo File**: `docs/brand/assets/logo.svg`
- **Symbol File**: `docs/brand/assets/symbol.svg`

### Implementation Notes

- SVG format ensures crisp rendering at any size
- Optimized for web and print applications
- Compatible with modern design tools and development workflows

## Brand Evolution

The Artur brand is designed to be:

- **Timeless**: Classic compass metaphor that won't feel outdated
- **Scalable**: Can grow with the framework's ecosystem
- **Memorable**: Simple, distinctive symbol that aids recognition
- **Meaningful**: Every element reinforces the core value of clear navigation
